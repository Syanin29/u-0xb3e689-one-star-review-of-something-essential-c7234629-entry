One fixed deadpan one-star review of gravity, written to `/output/entry.txt`
by a tiny deterministic Python program — no network, no randomness, no model
calls; both runs write the same bytes.

> Gravity: keeps my feet on the ground and my phone on the floor.

63 characters — inside the gate's 1–160 range. Deadpan throughout, no winking,
no exclamation mark, one joke told cleanly, with the turn in the last four words.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
